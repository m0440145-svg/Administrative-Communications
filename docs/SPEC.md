# مواصفات منصة الاتصالات الإدارية (الإصدار 2.0)

وثيقة المتطلبات والتنفيذ: لكل بند من المتطلبات التسعة الحالة الفعلية في الكود **اليوم**، وما بقي في خارطة الطريق وسبب تأجيله.

**مفتاح الحالة:** ✅ منفَّذ ومُختبَر · 🟡 منفَّذ جزئيًا (القيد مذكور) · 🗺️ خارطة الطريق (غير منفَّذ)

## 0) المعمارية في سطور

| الطبقة | التقنية | الملاحظة |
|---|---|---|
| الخادم | Python 3.10+ (مكتبة قياسية فقط)، `ThreadingHTTPServer` | لا اعتماديات؛ `cryptography` اختيارية للتشفير عند الراحة |
| البيانات | SQLite (WAL) + مجلد مرفقات | نسخ احتياطي متّسق بواجهة `sqlite3.backup` |
| الواجهة | JavaScript خالص، RTL، PWA قابلة للتثبيت | لا مكتبات خارجية ولا CDN (سياسة CSP صارمة) |
| التوسعة | وحدات `ext_*.py` عبر نقاط ربط (`emit/on`, `EXT_*`) | كل وحدة تضيف جداولها ومساراتها دون تعديل النواة |

**الوحدات:** النواة `server.py` (المراسلات، الإحالات، الصلاحيات، المرفقات، التقارير) · `ext_core.py` (إشعارات، وسوم وبحث، اقتراحات وقواعد، قوالب، تفضيلات) · `ext_workflow.py` (مسارات عمل، توقيع، تفويض) · `ext_gov.py` (احتجاز، سلسلة السجل، نسخ احتياطي، استيراد، SSO، تشفير، KPI).

**الحجم المناسب:** عشرات إلى مئات المستخدمين ومئات الآلاف من المراسلات على خادم واحد. لما يفوق ذلك انظر «التوسع» أدناه.

## 4) أمان البيانات والامتثال

| المتطلب | الحالة | التنفيذ / القيد |
|---|---|---|
| تشفير أثناء النقل | ✅ | HTTPS مباشرًا (`ACP_TLS_CERT/KEY`، TLS ≥ 1.2، مُختبَر) أو خلف وكيل عكسي (الموصى به للإنتاج) |
| تشفير عند الراحة | 🟡 | **المرفقات**: Fernet (AES-128-CBC + HMAC) بمفتاح `ACP_ENC_KEY`؛ **يرفض الخادم البدء** إن طُلب التشفير دون المكتبة. **قاعدة البيانات**: تشفير القرص (BitLocker/LUKS) موصى به؛ SQLCipher 🗺️ |
| إدارة المفاتيح | 🟡 | تدوير مفاتيح التشفير (`ACP_ENC_KEY=جديد,قديم`)، مفتاح توقيع مستقل (`ACP_SIGN_KEY` أو ملف 0600)، توليد مفتاح بأمر `genkey`. تكامل KMS/HSM 🗺️ |
| نسخ احتياطي واسترجاع | ✅ | نسخة متّسقة (DB + مرفقات + مفتاح التوقيع) مع بيان بصمات، تلقائيًا كل 24 ساعة (قابل للضبط، تدوير 14 نسخة) أو يدويًا؛ استرجاع من سطر الأوامر مع تحقق البصمات ورفض الكتابة فوق قاعدة موجودة دون `--force`؛ النسخة التالفة تُرفض |
| سجل تدقيق مفصّل | ✅ | كل عملية مع المستخدم والـIP؛ **سلسلة بصمات** (hash chain): حذف/تعديل سجل في المنتصف يُكتشف بأمر واجهة/CLI. حد معروف: حذف **آخر** السجلات لا يمكن كشفه دون تثبيت خارجي للبصمة الأخيرة (🗺️ إرسالها دوريًا لخادم سجلات) |
| الامتثال | 🟡 | ضوابط داعمة لأنظمة حماية البيانات الشخصية (نظام PDPL السعودي ومعايير ISO 27001): أقل صلاحية، سرية بدرجات، سجل، احتجاز وإتلاف موثق، تقليل البيانات. **لا تُغني عن مراجعة قانونية/تقييم أثر ولا تمنح شهادة امتثال** |
| ضوابط أساسية | ✅ | PBKDF2-240k، قفل بعد 5 محاولات، جلسات 8 ساعات، إعادة إدخال كلمة المرور قبل التوقيع/الإتلاف، CSP/nosniff/Frame-deny، SQL بمعاملات، رفع بامتدادات مسموحة وأسماء عشوائية، بصمة عند كل تنزيل |

## إعدادات التشغيل (متغيرات البيئة)

| المتغير | الوصف |
|---|---|
| `ACP_HOST` `ACP_PORT` `ACP_DATA` | الاستماع (127.0.0.1:8080) ومجلد البيانات |
| `ACP_ADMIN_USER` `ACP_ADMIN_PASSWORD` | حساب المدير الأول |
| `ACP_TLS_CERT` `ACP_TLS_KEY` | تفعيل HTTPS مباشرة |
| `ACP_ENC_KEY` | مفتاح/مفاتيح Fernet لتشفير المرفقات (مفتاح جديد أولًا للتدوير) — يتطلب `pip install cryptography` |
| `ACP_SIGN_KEY` | مفتاح توقيع الاعتماد (الافتراضي ملف `data/sign.key`) |
| `ACP_SSO_HEADER` `ACP_SSO_SECRET` | الدخول الموحّد عبر وسيط موثوق (ترويسة اسم المستخدم + السر المشترك `X-SSO-Secret`) |
| `ACP_BACKUP_HOURS` `ACP_BACKUP_KEEP` | دورية النسخ الاحتياطي التلقائي (24، 0 لإيقافه) وعدد النسخ المحفوظة (14) |

أوامر الصيانة: `python server.py backup` · `restore <zip> [--force]` · `verify-audit` · `genkey`

## الأداء المقاس

قياس فعلي على بيانات **اصطناعية** (50,000 مراسلة، قاعدة 26MB، جهاز التطوير، مستخدم واحد، أفضل 3 محاولات). أوقات الاستجابة للخادم المحلي دون شبكة:

| العملية | الزمن |
|---|---|
| قائمة المراسلات (مدير النظام / مكتب الصادر / مدير وحدة / موظف عادي) | 72 / 120 / 180 / 13 ms |
| بحث نصي كامل FTS5 (أي دور) | 14–21 ms |
| لوحة المعلومات (مدير النظام / مكتب الصادر / موظف) | 143 / 224 / 10 ms |
| التقارير / مؤشرات KPI | 603 / 397 ms |
| تسجيل مراسلة (مع الفهرسة والإشعارات) | 39 ms |
| بناء فهرس البحث لـ50 ألف مراسلة (مرة واحدة عند أول تشغيل بعد الترقية) | 5 s |

**حدود هذا القياس:** مستخدم واحد دون تزامن، وبيانات عشوائية لا تعكس توزيع الواقع، وبلا مرفقات. معيار UAT رقم 13 (20 مستخدمًا متزامنًا) يُقاس في بيئتكم قبل الإطلاق. وقد كشف هذا القياس مشكلة (شرط الظهور بطيء لغير المدير: 2.5–4.5 ثانية) فصُحِّحت بفهارس واستعلام مجمّع، واختبارات الصلاحيات تغطي سلوكه.
