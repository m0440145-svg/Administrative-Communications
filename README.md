# منصة الاتصالات الإدارية

منصة متكاملة لإدارة **الصادر والوارد** للمراسلات **الخارجية والداخلية**: قيد برقم تسلسلي، أرشفة المرفقات، إحالة وتتبّع، صلاحيات حسب الدور ودرجة السرية، وسجل تدقيق كامل، مع واجهة API للتكامل مع الأنظمة القائمة.

لا تحتاج أي مكتبات خارجية: **Python 3.10+ فقط** (خادم + SQLite) وواجهة عربية RTL بـ JavaScript خالص.

## التشغيل

```bash
python server.py
```

ثم افتح <http://127.0.0.1:8080>. عند أول تشغيل يُنشأ المستخدم `admin` وتُطبع كلمة مروره المؤقتة في الطرفية (يُطلب تغييرها عند أول دخول). أو حدّدها مسبقًا بـ `ACP_ADMIN_PASSWORD`.

| المتغير | الافتراضي | الوصف |
|---|---|---|
| `ACP_HOST` | `127.0.0.1` | عنوان الاستماع. للشبكة الداخلية استخدم `0.0.0.0` **خلف HTTPS** (انظر الأمان) |
| `ACP_PORT` | `8080` | المنفذ |
| `ACP_DATA` | `./data` | مجلد قاعدة البيانات والمرفقات (**يُنسخ احتياطيًا**) |
| `ACP_ADMIN_PASSWORD` | عشوائية | كلمة مرور المدير الأولى |

## الوظائف

- **التسجيل والترقيم:** `EXT-IN-2026-00001` (وارد خارجي) · `EXT-OUT` · `INT-IN` · `INT-OUT`، ترقيم تسلسلي سنوي آمن من التزاحم.
- **تنظيم الوثائق:** الجهة، مرجعها، التاريخ (ميلادي مع الهجري في العرض)، التصنيف، الأولوية، الاستحقاق، الربط بين الأصل والرد، مرفقات متعددة ببصمة SHA-256.
- **التتبّع:** إحالات بتوجيهات ومواعيد، قائمة «معاملاتي»، حالات (جديدة/محالة/قيد المعالجة/منجزة/مؤرشفة)، تنبيه التأخر، خط زمني لكل مراسلة.
- **البحث والتقارير:** بحث وفلاتر متعددة، لوحة مؤشرات، تصدير CSV (آمن لـ Excel).
- **الإدارة:** مستخدمون وإدارات وأدوار ودرجات سرية، سجل تدقيق للقراءة فقط.

### الأدوار

| الدور | الصلاحية |
|---|---|
| `admin` مدير النظام | كل شيء + الإدارة والتدقيق والتكامل |
| `clerk` مكتب الصادر والوارد | تسجيل الخارجي والداخلي ورؤية الكل (ضمن درجة سريته) |
| `manager` مدير إدارة | مراسلات إدارته والمرتبطة به |
| `employee` موظف | الداخلي فقط، ويرى ما سجّله أو أُحيل/أُسند إليه |

**درجات السرية:** 0 عادي · 1 سري · 2 سري للغاية. لا يرى المراسلةَ ولا تُحال إليه إلا من تساوي صلاحيتُه درجتَها أو تزيد (القاعدة تسري على الجميع عدا مدير النظام الذي يرى كل شيء، ولذلك يُنصح بحصر هذا الدور في أضيق نطاق).

## التكامل مع الأنظمة القائمة

**1) مفتاح API** (من «التكامل» في القائمة): يعمل بصلاحيات مستخدم خدمي تختاره. أرسله في الترويسة `X-API-Key`:

```bash
curl -X POST http://HOST:8080/api/correspondences \
  -H "X-API-Key: acp_..." -H "Content-Type: application/json" \
  -d '{"scope":"external","direction":"incoming","subject":"طلب","party":"وزارة المالية","doc_date":"2026-11-04"}'
```

أهم المسارات: `GET/POST /api/correspondences` · `GET/PUT /api/correspondences/{id}` · `POST /api/correspondences/{id}/transfers` · `POST /api/correspondences/{id}/attachments` (جسم الطلب = الملف، الترويسة `X-Filename` مُرمَّزة URL) · `GET /api/attachments/{id}` · `GET /api/export` · `GET /api/dashboard`.

**2) Webhooks:** تُرسل `POST` JSON عند `correspondence.created` / `correspondence.referred` / `correspondence.status` مع الترويسة `X-ACP-Signature: sha256=<HMAC(secret, body)>` للتحقق. لا تُرسَل عناوين المراسلات السرية.

**3) الدخول الموحّد (SSO/LDAP):** يوضع خلف وسيط مصادقة (مثل oauth2-proxy) أو يُوسَّع `login()` في `server.py` للتحقق من LDAP/AD.

## الأمان

- كلمات المرور: PBKDF2-SHA256 (240 ألف دورة) مع ملح؛ سياسة 8 أحرف بحروف وأرقام؛ قفل الحساب 15 دقيقة بعد 5 محاولات فاشلة.
- جلسات برمز عشوائي مُخزَّن مُجزَّأً، تنتهي بعد 8 ساعات؛ رمز Bearer (لا كوكيز) فلا CSRF.
- تحكم بالوصول على مستوى الاستعلام (الدور + السرية + الارتباط) يشمل التنزيل والتصدير والإحالة.
- استعلامات SQL بمعاملات، ترويسات CSP/`nosniff`/`X-Frame-Options`، وإدراج النصوص في الواجهة بـ `textContent` فقط.
- المرفقات: قائمة امتدادات مسموحة، حد 20MB، أسماء تخزين عشوائية، تنزيل كـ attachment، والتحقق من البصمة عند كل تنزيل.
- لا حذف للمراسلات أو المرفقات (حفظ للسجل)؛ كل عملية في سجل التدقيق.

**قبل الإنتاج:** ضع النظام خلف وكيل عكسي بـ **HTTPS** (nginx/Caddy/IIS)، خذ نسخًا احتياطية دورية لمجلد `ACP_DATA`، وفعّل تشفير القرص للبيانات السرية. الخادم المدمج مناسب لجهات صغيرة/متوسطة؛ للأحمال الكبيرة انقل `SCHEMA` إلى PostgreSQL.
