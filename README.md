# منصة الاتصالات الإدارية

منصة متكاملة لإدارة **الصادر والوارد** للمراسلات **الخارجية والداخلية**: قيد برقم تسلسلي، أرشفة المرفقات، إحالة وتتبّع، صلاحيات حسب الدور ودرجة السرية، وسجل تدقيق كامل، مع واجهة API للتكامل مع الأنظمة القائمة.

لا تحتاج أي مكتبات خارجية: **Python 3.10+ فقط** (خادم + SQLite) وواجهة عربية RTL بـ JavaScript خالص.

## التشغيل

```bash
python server.py
```

ثم افتح <http://127.0.0.1:8080>. عند أول تشغيل يُنشأ المستخدم `admin` وتُطبع كلمة مروره المؤقتة في الطرفية (يُطلب تغييرها عند أول دخول). أو حدّدها مسبقًا بـ `ACP_ADMIN_PASSWORD`.

| المتغير | الافتراضي | الوصف |
|---|---|---|
| `ACP_HOST` | `127.0.0.1` | عنوان الاستماع. للشبكة الداخلية استخدم `0.0.0.0` **خلف HTTPS** (انظر الأمان) |
| `ACP_PORT` | `8080` | المنفذ |
| `ACP_DATA` | `./data` | مجلد قاعدة البيانات والمرفقات (**يُنسخ احتياطيًا**) |
| `ACP_ADMIN_PASSWORD` | عشوائية | كلمة مرور المدير الأولى |

## الوظائف

- **التسجيل والترقيم:** `EXT-IN-2026-00001` (وارد خارجي) · `EXT-OUT` · `INT-IN` · `INT-OUT`، ترقيم تسلسلي سنوي آمن من التزاحم.
- **تنظيم الوثائق:** الجهة، مرجعها، التاريخ (ميلادي مع الهجري في العرض)، التصنيف، الأولوية، الاستحقاق، الربط بين الأصل والرد، مرفقات متعددة ببصمة SHA-256.
- **التتبّع:** إحالات بتوجيهات ومواعيد، قائمة «معاملاتي»، حالات (جديدة/محالة/قيد المعالجة/منجزة/مؤرشفة)، تنبيه التأخر، خط زمني لكل مراسلة.
- **البحث والتقارير:** بحث وفلاتر متعددة، لوحة مؤشرات، تصدير CSV (آمن لـ Excel).
- **الإدارة:** مستخدمون وإدارات وأدوار ودرجات سرية، سجل إجراءات للقراءة فقط.

### إعدادات النظام (للمدير)

- **الوحدات:** إضافة وتعديل وتعطيل الوحدات (الإدارات والأقسام).
- **الموظفون:** الاسم والمسمى والجوال والبريد والوحدة والدور ودرجة الخصوصية، وتصفير كلمة المرور والتعطيل.
- **التصنيفات والخصوصية:** تصنيف الوثيقة قائمة يديرها المدير (الافتراضي: عاجل جدا، عاجل، مهم جدا، مهم، سري، عادي، غير مهم) ولكل تصنيف لون ودرجة خصوصية ووسم «عاجل».
- **الصلاحيات:** مصفوفة أدوار × صلاحيات (تسجيل الخارجي، التصدير والتقارير، الاطلاع على الكل، تحديث وإحالة أي مراسلة).
- **التقارير والمؤشرات:** حسب الوحدة والتصنيف والحالة والنوع والشهر وأكثر الجهات، مع فلاتر التاريخ والاتجاه، وطباعة وتصدير CSV.

### الأدوار

| الدور | الصلاحية |
|---|---|
| `admin` مدير النظام | كل شيء + الإدارة والتدقيق والتكامل |
| `clerk` مكتب الصادر والوارد | تسجيل الخارجي والداخلي ورؤية الكل (ضمن درجة سريته) |
| `manager` مدير إدارة | مراسلات إدارته والمرتبطة به |
| `employee` موظف | الداخلي فقط، ويرى ما سجّله أو أُحيل/أُسند إليه |

**درجات السرية:** 0 عادي · 1 سري · 2 سري للغاية. لا يرى المراسلةَ ولا تُحال إليه إلا من تساوي صلاحيتُه درجتَها أو تزيد (القاعدة تسري على الجميع عدا مدير النظام الذي يرى كل شيء، ولذلك يُنصح بحصر هذا الدور في أضيق نطاق).

## الإصدار 2.0 — ما أُضيف

> التفصيل الكامل لكل متطلب (✅ منفَّذ / 🟡 جزئي / 🗺️ خارطة الطريق) في [docs/SPEC.md](docs/SPEC.md)، وخطة الترحيل وUAT والتدريب في [docs/MIGRATION_AND_ROLLOUT.md](docs/MIGRATION_AND_ROLLOUT.md).

- **الأرشيف والبحث:** مجلدات متدرجة، وسوم، بحث نصي كامل (FTS5) بتطبيع عربي يشمل نص المرفقات النصية.
- **الذكاء:** اقتراح نوع/مجلد/تصنيف/وحدة/مُسنَد إليه (تعلّم من الأرشيف + قواعد توجيه صريحة بتطبيق تلقائي)، وقوالب خطابات.
- **سير العمل:** مسارات عمل (مراجعة/اعتماد) قابلة للتخصيص، اعتماد رسمي بتوقيع إلكتروني مع تحقق من سلامة الوثيقة، تفويض الصلاحيات.
- **التنبيه:** إشعارات داخلية، تذكير بالمواعيد، وتنبيه عند انحراف الأداء. KPI: الالتزام بالمواعيد، زمن الاستجابة، نسبة الرد، أعمار المفتوح، أعباء الموظفين.
- **الحوكمة والأمان:** سياسات احتجاز وإتلاف موثّق وتجميد قانوني، سجل إجراءات مترابط بالبصمات (يكشف التلاعب)، نسخ احتياطي واسترجاع، تشفير المرفقات (اختياري)، HTTPS، دخول موحّد SSO.
- **التشغيل:** استيراد موظفين (موارد بشرية) ومراسلات قديمة بفحص تجريبي، تطبيق قابل للتثبيت (PWA)، سمات وفلاتر محفوظة.

### أوامر الصيانة ومتغيرات إضافية

```bash
python server.py backup              # نسخة احتياطية (قاعدة + مرفقات + مفتاح التوقيع) في data/backups
python server.py restore نسخة.zip    # أوقف الخادم أولًا؛ أضف --force للكتابة فوق قاعدة موجودة
python server.py verify-audit        # التحقق من سلامة سلسلة سجل الإجراءات
python server.py genkey              # توليد مفتاح تشفير المرفقات (يتطلب pip install cryptography)
```

| المتغير | الوصف |
|---|---|
| `ACP_TLS_CERT` `ACP_TLS_KEY` | تفعيل HTTPS مباشرة |
| `ACP_ENC_KEY` | تشفير المرفقات عند الراحة (مفتاح جديد أولًا للتدوير: `جديد,قديم`) |
| `ACP_SSO_HEADER` `ACP_SSO_SECRET` | الدخول الموحّد عبر وسيط موثوق (IIS/oauth2-proxy/nginx) |
| `ACP_BACKUP_HOURS` `ACP_BACKUP_KEEP` | دورية النسخ التلقائي (24؛ 0 لإيقافه) وعدد المحفوظ (14) |
| `ACP_SIGN_KEY` | مفتاح توقيع الاعتماد (الافتراضي ملف `data/sign.key`) |

**ما لم يُنفَّذ بعد (خارطة الطريق):** OCR عربي، بريد إلكتروني (استلام/إرسال)، LDAP مباشر، توقيع رقمي معتمد قانونيًا (PKI/نفاذ)، تطبيق جوال أصلي. تفاصيل الأسباب في المواصفة.

## الإصدار 2.1 — ما أُضيف (ملخص)

> مطابقة تفصيلية بند بند مع المرجع الفني (✅ منفَّذ / 🟡 جزئي / ❌ غير منفَّذ مع السبب): [docs/SPEC_V21.md](docs/SPEC_V21.md).

- **سير العمل:** مراحل **متوازية** وخطوات **شرطية**؛ حالات جديدة (مسودة، قيد المراجعة، بانتظار التوقيع) تتبع المرحلة آليًا؛ **SLA بساعات العمل** وتصعيد عند 75٪ و100٪ وتلوين أحمر.
- **الوثائق:** **الملف الموحّد** بخط زمني، تهميشات وأختام على طبقة منفصلة، معاينة بعلامة مائية ديناميكية، **ملصق QR + Code128** وفتح المعاملة بالمسح، **الخطاب الرسمي** بترويسة وختم، كشف **التكرار**، بحث **AND/OR/NOT**، تثبيت وأعمدة مخصصة، **تصدير Excel**.
- **القنوات:** إشعارات **لحظية** (SSE) + **بريد SMTP** + **SMS** (بوابة HTTP) بصندوق صادر وإعادة محاولة؛ **استقبال البريد** (EML/IMAP) كمعاملات؛ إرسال الصادر بالبريد بتتبع الحالة.
- **الأمان:** **MFA (TOTP)** + رموز استرداد + OTP عند التوقيع، سجل إجراءات **غير قابل للتعديل** (محفّزات + سلسلة بصمات) مع تسجيل الاطلاع ومحاولات الوصول المرفوضة، **ABAC صارم** لـ«سري للغاية»، **OAuth2/JWT** و**OpenAPI** (`/apidocs.html`).
- **الحوكمة:** **لجنة الوثائق** (اعتمادات متعددة بفصل المهام) للإتلاف، **أرشيف وسيط (بارد)**، نسخة احتياطية بديلة، مزامنة **الإجازات ← تفويض تلقائي**، تغذية **BI**.
- **التقارير:** KPI أوسع (SLA، زمن لكل وحدة/موظف، نسبة الإلكتروني)، **تقارير مجدولة بـExcel**، كشف **انحراف إحصائي**.
- **الواجهة:** واجهة قيادة (اعتماد بنقرة)، عرض مقسّم، اختصارات لوحة المفاتيح.

### متغيرات تشغيل إضافية

| المتغير | الوصف |
|---|---|
| `ACP_SMTP_HOST` `ACP_SMTP_PORT` `ACP_SMTP_USER` `ACP_SMTP_PASS` `ACP_SMTP_FROM` `ACP_SMTP_TLS` | البريد الصادر (`starttls` افتراضيًا، أو `ssl`/`none`) |
| `ACP_SMS_URL` `ACP_SMS_TOKEN` `ACP_SMS_SENDER` | بوابة SMS عبر HTTP (JSON: to, message, sender) |
| `ACP_IMAP_HOST` `ACP_IMAP_USER` `ACP_IMAP_PASS` `ACP_IMAP_FOLDER` `ACP_IMAP_ACTOR` `ACP_IMAP_SECONDS` | استقبال البريد الوارد كمعاملات |
| `ACP_TLS_MIN=1.3` | إلزام TLS 1.3 عند تفعيل HTTPS المباشر |
| `ACP_BACKUP_COPY_DIR` | مسار النسخة الاحتياطية البديلة (مشاركة شبكية/قرص خارجي) |
## هوية الجهة وألوان المنصة (إضافة)

من إعدادات النظام ← «الهوية والترويسة» (مدير النظام):

- **ألوان المنصة**: اللون الأساسي ولون القائمة الجانبية بمنتقي ألوان مع معاينة فورية وزر استعادة الافتراضي. تُطبَّق على السمة الفاتحة، وتبقى السمة الداكنة بألوانها المضبوطة للتباين، ويُرفض لون قائمة فاتح جدًا.
- **الشعار**: PNG/JPEG/WebP حتى 1MB، يُتحقق من محتوى الملف (لا الامتداد) ولا يُقبل SVG؛ يظهر في القائمة وصفحة الدخول وصفحة «من نحن» والخطاب الرسمي، ويدخل ضمن النسخ الاحتياطي (`branding/`).
- **بيانات الجهة**: الاسم (عربي/إنجليزي)، العنوان، الهاتف، البريد، الموقع، رسالة صفحة الدخول.
- **الترويسة والتذييل والختم** للخطاب الرسمي (كما كانت، مع إضافة بيانات التواصل تلقائيًا).
- **من نحن، الرؤية، الرسالة، الأهداف**: تظهر لجميع المستخدمين في «حسابي ← من نحن».

الواجهة البرمجية: `GET /api/public/branding` و`GET /api/public/logo` (بلا مصادقة، الاسم والألوان والشعار فقط)، `GET /api/org/profile` (مستخدم مسجّل)، `GET/PUT /api/admin/org`، `POST/DELETE /api/admin/org/logo` (مدير). الوحدة: `ext_brand.py`، الواجهة: `static/brand.js`، الاختبارات: `tests/test_brand.py`.

## المسح الضوئي والباركود وأنواع الملفات (إضافة)

- **طباعة الباركود**: من أي مراسلة (وارد/صادر) زر «🖨 طباعة الباركود» يفتح الطباعة مباشرة، وصفحة «ملصق QR» تتيح اختيار الحجم (60×40 حراري، 90×55، أو **ختم استلام** 100×70 باسم الجهة والتاريخ) وعدد النسخ وإظهار الموضوع (يُحجب للسرية).
- **المسح والاستلام** (القائمة: المراسلات ← المسح والاستلام): سحب وإفلات، 📷 تصوير بكاميرا الجوال، **دمج عدة صور في PDF واحد**، ثم نسب الملف لمراسلة جديدة (وارد/صادر) أو قائمة برقم القيد.
- **الماسح الضوئي مباشرة (مجلد المسح الساخن)**: اضبط `ACP_SCAN_DIR` على المجلد الذي يحفظ فيه الماسح (المسح إلى مجلد/مشاركة شبكية) وأعد تشغيل الخادم. الملف المسمّى برقم القيد أولًا (`IN-00012__عقد.pdf`) يُرفق تلقائيًا بالمراسلة؛ وغيره يدخل صندوق المسح. المعالَج يُنقل إلى `_processed` ويُحذف بعد 14 يومًا، والمرفوض إلى `_failed`. `ACP_SCAN_SECONDS` لفترة الفحص (10 ث افتراضيًا). المتصفح لا يستطيع تشغيل ماسحات TWAIN/WIA مباشرة، لذا هذا هو المسار المعتمد.
- **أنواع الملفات**: قائمة موسّعة (مكتب، OpenDocument، صور، أرشيفات، صوت وفيديو، CAD، توقيعات …) وإضافة المدير لأنواع أخرى من «الملفات والمسح» مع حد أقصى للحجم (1–200MB). محظور دائمًا: التنفيذيات والسكربتات وصفحات الويب وSVG وملفات الماكرو. الوحدة: `ext_scan.py`، الواجهة: `static/scan.js`، الاختبارات: `tests/test_scan.py`.

## التكامل مع الأنظمة القائمة

**1) مفتاح API** (من «التكامل» في القائمة): يعمل بصلاحيات مستخدم خدمي تختاره. أرسله في الترويسة `X-API-Key`:

```bash
curl -X POST http://HOST:8080/api/correspondences \
  -H "X-API-Key: acp_..." -H "Content-Type: application/json" \
  -d '{"scope":"external","direction":"incoming","subject":"طلب","party":"وزارة المالية","doc_date":"2026-11-04"}'
```

أهم المسارات: `GET/POST /api/correspondences` · `GET/PUT /api/correspondences/{id}` · `POST /api/correspondences/{id}/transfers` · `POST /api/correspondences/{id}/attachments` (جسم الطلب = الملف، الترويسة `X-Filename` مُرمَّزة URL) · `GET /api/attachments/{id}` · `GET /api/export` · `GET /api/dashboard`.

**2) Webhooks:** تُرسل `POST` JSON عند `correspondence.created` / `correspondence.referred` / `correspondence.status` مع الترويسة `X-ACP-Signature: sha256=<HMAC(secret, body)>` للتحقق. لا تُرسَل عناوين المراسلات السرية.

**3) الدخول الموحّد (SSO/LDAP):** يوضع خلف وسيط مصادقة (مثل oauth2-proxy) أو يُوسَّع `login()` في `server.py` للتحقق من LDAP/AD.

## الأمان

- كلمات المرور: PBKDF2-SHA256 (240 ألف دورة) مع ملح؛ سياسة 8 أحرف بحروف وأرقام؛ قفل الحساب 15 دقيقة بعد 5 محاولات فاشلة.
- جلسات برمز عشوائي مُخزَّن مُجزَّأً، تنتهي بعد 8 ساعات؛ رمز Bearer (لا كوكيز) فلا CSRF.
- تحكم بالوصول على مستوى الاستعلام (الدور + السرية + الارتباط) يشمل التنزيل والتصدير والإحالة.
- استعلامات SQL بمعاملات، ترويسات CSP/`nosniff`/`X-Frame-Options`، وإدراج النصوص في الواجهة بـ `textContent` فقط.
- المرفقات: قائمة امتدادات مسموحة، حد 20MB، أسماء تخزين عشوائية، تنزيل كـ attachment، والتحقق من البصمة عند كل تنزيل.
- لا حذف للمراسلات أو المرفقات (حفظ للسجل)؛ كل عملية في سجل التدقيق.

**قبل الإنتاج:** ضع النظام خلف وكيل عكسي بـ **HTTPS** (nginx/Caddy/IIS)، خذ نسخًا احتياطية دورية لمجلد `ACP_DATA`، وفعّل تشفير القرص للبيانات السرية. الخادم المدمج مناسب لجهات صغيرة/متوسطة؛ للأحمال الكبيرة انقل `SCHEMA` إلى PostgreSQL.

## الشريط العلوي وعلامات الصفحات (مستلهم من vue-element-admin)

`static/adminui.js` يضيف دون تغيير ما سبق: زر طيّ القائمة الجانبية (يُحفظ)، ومسار التنقل (Breadcrumb)، وبحث في القوائم (Ctrl+K) يشمل تبويبات الإدارة، وملء الشاشة، وكثافة العرض (مريح/مضغوط)، وجرس الإشعارات بعدّاده، وسجل أخطاء الواجهة للمدير (`#/errors`)، وعلامات الصفحات المفتوحة (Tags View: إغلاق منفرد أو «إغلاق الأخرى»)، وزر العودة للأعلى.

## جداول إدارية متقدمة (مستلهمة من Vuestic Admin)

`static/tables.js` يحسّن كل الجداول تدريجيًا دون تعديل أكواد الصفحات: **فرز بالنقر على العنوان** (قائمة المعاملات تُفرز على الخادم بكل النتائج عبر `?by=subject&dir=desc` بقائمة بيضاء للأعمدة: ref/subject/party/date/doc_date/status/priority)، و**تصفية سريعة** مع عدّاد، و**إظهار/إخفاء الأعمدة**، و**تصدير CSV** (بترميز يدعم العربية وحماية من حقن الصيغ)، وعنوان ثابت، و**تحويل الجدول إلى بطاقات على الجوال** (≤700px). الاختبارات: `tests/test_tables.py`.
